# Sistema de Leilões

## 📌 Sobre o Projeto

O **Sistema de Leilões** é um sistema informatizado desenvolvido para auxiliar no gerenciamento das rotinas de uma casa de leilões.
O projeto tem como objetivo facilitar o **cadastro de produtos**, o **acompanhamento de vendas** e a **organização das informações**, oferecendo mais controle e segurança aos processos do negócio.

Este sistema faz parte de um projeto acadêmico que aplica boas práticas de desenvolvimento de software, incluindo o uso de controle de versão com Git e GitHub.

---

## ⚙️ Funcionalidades

- Cadastro de produtos para leilão
- Visualização e acompanhamento de vendas
- Organização das informações em banco de dados
- Integração com sistema de persistência de dados

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Banco de Dados:** MySQL
- **IDE Sugerida:** Eclipse ou IntelliJ IDEA
- **Interface Gráfica:** Java Swing _(quando aplicável)_
- **Versionamento:** Git e GitHub

---

## 🗄️ Banco de Dados

- **SGBD:** MySQL

O script de criação do banco encontra-se no projeto.
